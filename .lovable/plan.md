# Entrepreneur Showcase and Class Platform Logos

## What will change
- Replace the generic class-link icons with recognizable Google Classroom and Figma logos while preserving both existing links.
- Add a fixed circular showcase button in the lower-right corner.
- Open a compact entrepreneur profile panel above the button with a portrait, name, role/company, demographic tags, origin story, signature achievement, and career overview.
- Include 25 varied entrepreneur profiles spanning genders, age groups, backgrounds, and industries.
- Add previous/next controls, a `1 of 25` counter, looping navigation, close control, and keyboard support for Left, Right, and Escape.
- Add smooth open/close and profile-change motion, high-contrast support, mobile-safe sizing, and an internal scrollbar for longer profiles.

## Technical details
- Keep all content and behavior local to the existing React page; no account, storage, or server changes.
- Use lightweight inline brand marks for the two known class platforms and existing icon utilities for showcase controls.
- Preserve the current page navigation, accessibility controls, and class-link destinations.
- Verify the live page at desktop and mobile sizes, including keyboard controls and build status.
